# Коментар Закона о заштити корисника финансијских услуга

Коментар српског прописа: **Закон о заштити корисника финансијских услуга** („Службени гласник РС”, број 19/2025). Обухвата **81 јединицу** (чланове 1–81) у 4 поглавља коментара; уз сваки члан дат је дословни текст одредбе и коментар.

Стање прописа према: редакцијски пречишћен текст Правно-информационог система Републике Србије, основни текст објављен у „Службеном гласнику РС”, број 19 од 6. марта 2025, без каснијих измена у извору; текст преузет 2. октобра 2026. Закон се примењује од 1. јула 2025. године, уз изузетке из чл. 75, 76. и 81.

## Садржај

Види [INDEX.md](INDEX.md). Опис метода у [00-uvod.md](00-uvod.md).

1. Основне одредбе (чл. 1–16)
2. Информисање у предуговорној фази, процена кредитне способности и садржај уговора (чл. 17–34)
3. Измене уговора, променљива каматна стопа, посебна права корисника и повезани уговори (чл. 35–54)
4. Саветодавне услуге, уговори на даљину, неправичне одредбе, заштита права, финансијске погодбе, надзор, казнене и завршне одредбе (чл. 55–81)
